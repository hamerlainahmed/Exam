# منصة تسيير وحراسة الاختبارات المدرسية (ReactJS + Vite)

منصة ويب عربية (RTL) مرنة ومعمّمة لتوزيع قاعات الاختبارات وبرمجة حراسة الأساتذة بعدالة تامة، متوافقة مع ملفات الرقمنة الجزائرية (`.xls` للمستخدمين و`.xlsx` لإحصائيات التلاميذ).

## المميزات الرئيسية
- تخصيص مرن لعدد القاعات العادية مع تفعيل/تعطيل المخابر والورشات وتحديد قاعات الطابق الأرضي.
- استيراد مباشر لملف المستخدمين من الرقمنة (`.xls`) مع فرز آلي لرتبة **أستاذ** ومادته.
- استيراد ملف إحصائيات التلاميذ (`.xlsx`) وحرية تقسيم الأفواج وتشكيل المجموعات.
- محرك حراسة آلي يضمن التساوي في عدد الحراسات، ضبط الاحتياط (`اح`)، منع تكرار نفس القسم، ومنع الأستاذ من حراسة مادته.
- مركز طباعة A4 جاهز: 4 جداول فردية في الورقة (أو 2 في الورقة)، كشف استلام وإرجاع أوراق الإجابة للأمانة، وكشف الإلصاق اليومي.
- دمج **المستشار الذكي (Gemini API)** بمفتاح المستخدم المحلي.

## التشغيل المحلي
```bash
npm install
npm run dev
```

## النشر المجاني على Vercel أو Netlify
1. فك الضغط عن هذا المشروع وارفع ملفاته إلى مستودع جديد في **GitHub**.
2. اربط المستودع بمنصة **Vercel** أو **Netlify** ليتم بناء المنصة ونشرها تلقائياً برابط مباشر.
